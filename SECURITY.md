# Security Policy

## Supported Versions

Security fixes land on `master` first and are shipped forward into release branches and hotfix branches.

## Reporting

Do not open public GitHub issues for exploitable security problems.

Email the maintainers with:

- affected surface (`apps/desktop`, `services/local-sidecar`, `apps/web`, `services/cloud-api`)
- reproduction steps
- impact assessment
- whether the issue requires credential rotation or forced logout

## Triage Expectations

- We acknowledge reports within 3 business days.
- We prefer a private repro or proof of concept over screenshots alone.
- We will coordinate disclosure timing once a patch is available.
